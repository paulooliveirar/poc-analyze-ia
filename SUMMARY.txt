================================================================================
🎓 EXEMPLO BÁSICO
================================================================================

from src.football_detector import FootballDetector

# Inicializar
detector = FootballDetector(
    model_path="yolov8n.pt",      # Usar modelo nano
    conf_threshold=0.45            # Limiar de confiança 45%
)

# Usar câmera
detector.process_camera(camera_id=0)

# Ou processar vídeo
detector.process_video("partida.mp4", "resultado.mp4")

Pressione 'Q' para parar!

================================================================================
🎓 TREINAR COM SEUS DADOS
================================================================================

1. Preparar dataset no Roboflow (https://roboflow.com/)
   - Anotar jogadores, bola, etc.
   - Exportar em formato YOLOv8

2. Treinar:
   from src.train_custom_model import train_football_model
   
   train_football_model(
       dataset_path="/seu_dataset/data.yaml",
       epochs=100,
       batch_size=16
   )

3. Usar modelo treinado:
   detector = FootballDetector("runs/detect/football_detector/weights/best.pt")

🔍 RESOLUÇÃO DE PROBLEMAS
================================================================================

❌ "No module named 'ultralytics'"
   ✓ pip install ultralytics --upgrade

❌ Câmera não funciona
   ✓ Tente camera_id=1 ou 2
   ✓ Verifique permissões: v4l2-ctl --list-devices

❌ Muito lento
   ✓ Use yolov8n.pt (nano)
   ✓ Instale GPU support (CUDA)
   ✓ Reduza resolução

❌ CUDA não detectado
   ✓ pip install torch --index-url https://download.pytorch.org/whl/cu118
